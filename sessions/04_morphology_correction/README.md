# جلسهٔ ۰۴ — واژه‌های ایست، ریشه‌یابی، بن‌واژه‌سازی و اصلاح املای فارسی

**زمان:** ۱۲۰ دقیقه  
**سطح:** کارشناسی  
&#x2067;**پیش‌نیاز:** جلسه‌های ۰۱ تا ۰۳، &#x2066;Python&#x2069; مقدماتی، &#x2066;regex&#x2069; و توکن‌سازی واژه&#x2069;  
&#x2067;**وابستگی نرم‌افزاری:** در تمرین‌های اصلی فقط &#x2066;Python Standard Library&#x2069; لازم است؛ &#x2066;JupyterLab&#x2069; برای اجرای &#x2066;notebook&#x2069; استفاده می‌شود. مقایسه با &#x2066;Hazm&#x2069; اختیاری است.&#x2069;

## هدف جلسه

&#x2067;در این جلسه دانشجو چهار عملیات متفاوت را روی متن فارسی پیاده‌سازی و مقایسه می‌کند: حذف واژه‌های ایست متناسب با وظیفه (&#x2066;task-aware&#x2069;)، ریشه‌یابی قاعده‌محور، بن‌واژه‌سازی واژه‌نامه‌ای، و پیشنهاد اصلاح املایی بر اساس فاصلهٔ ویرایشی &#x2066;Levenshtein&#x2069;. تمرکز بر آزمون‌پذیری، خطاها و محدودیت‌های هر روش است؛ فهرست کوچک واژه‌های ایست و واژه‌نامه فقط برای آموزش ساخته شده و منبع مرجع عمومی نیست.&#x2069;

## خروجی‌های یادگیری

- &#x2067;توضیح دهید چرا حذف واژه‌های ایست ممکن است برای یک مدل &#x2066;BoW&#x2069; مفید و برای تحلیل احساسات، ترجمه یا تحلیل نحوی زیان‌بار باشد؛&#x2069;
- &#x2067;پیاده‌سازی و آزمون یک ریشه‌یاب قاعده‌محور فارسی ساده با محدودیت حداقل طول ریشه؛&#x2069;
- &#x2067;تفکیک &#x2066;stem&#x2069; و &#x2066;lemma&#x2069; و پیاده‌سازی بن‌واژه‌سازی (&#x2066;lemmatization&#x2069;) با &#x2066;lookup&#x2069; واژه‌نامه؛&#x2069;
- &#x2067;محاسبهٔ فاصلهٔ &#x2066;Levenshtein&#x2069; در سطح نویسه با برنامه‌ریزی پویا؛&#x2069;
- &#x2067;رتبه‌بندی پیشنهادهای اصلاح املایی بر اساس فاصله، فراوانی و ترتیب قطعی؛&#x2069;
- &#x2067;تحلیل بیش‌ریشه‌یابی، واژهٔ ناشناخته و اصلاح نادرست (&#x2066;false correction&#x2069;).&#x2069;

## اجرا

از ریشهٔ مخزن:

```bash
python -m pip install -r requirements.txt
python scripts/check_environment.py
jupyter lab
```
