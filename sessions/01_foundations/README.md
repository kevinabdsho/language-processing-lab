# جلسه ۰۱ — مبانی پردازش متن فارسی

**زمان:** ۱۲۰ دقیقه  
**سطح:** کارشناسی  
&#x2067;**پیش‌نیاز:** Python مقدماتی&#x2069;  
&#x2067;**وابستگی نرم‌افزاری برای تمرین‌ها:** فقط Python Standard Library&#x2069;

## هدف اصلی

&#x2067;در این جلسه قرار نیست یک tokenizer کامل یا مدل NLP بسازیم. هدف این است که قبل از مدل‌سازی بفهمیم «متن» در رایانه چگونه نمایش داده می‌شود و چرا کیفیت نمایش متن فارسی مستقیماً روی آمار داده و خروجی مدل اثر می‌گذارد.&#x2069;

## خروجی‌های یادگیری

پس از پایان جلسه باید بتوانید:

- &#x2067;تفاوت Unicode و UTF-8 را توضیح دهید؛&#x2069;
- &#x2067;متن فارسی را encode/decode کنید؛&#x2069;
- اختلاف نویسه‌های `ي/ی` و `ك/ک` را تشخیص دهید؛
- &#x2067;تفاوت NFC با normalization فارسی را توضیح دهید؛&#x2069;
- &#x2067;نقش ZWNJ (&#x2066;`U+200C`&#x2069;) را در فارسی بررسی کنید؛&#x2069;
- &#x2067;یک normalization policy کوچک و قابل‌آزمون پیاده‌سازی کنید؛&#x2069;
- &#x2067;کیفیت یک corpus کوچک را ممیزی کنید؛&#x2069;
- &#x2067;تغییرات تعداد token/type را قبل و بعد از normalization تحلیل کنید.&#x2069;
