# جلسه ۰۱ — مبانی پردازش متن فارسی

**زمان:** ۱۲۰ دقیقه  
**سطح:** کارشناسی  
**پیش‌نیاز:** Python مقدماتی  
**وابستگی نرم‌افزاری برای تمرین‌ها:** فقط Python Standard Library

## هدف اصلی

در این جلسه قرار نیست یک tokenizer کامل یا مدل NLP بسازیم. هدف این است که قبل از مدل‌سازی بفهمیم «متن» در رایانه چگونه نمایش داده می‌شود و چرا کیفیت نمایش متن فارسی مستقیماً روی آمار داده و خروجی مدل اثر می‌گذارد.

## خروجی‌های یادگیری

پس از پایان جلسه باید بتوانید:

- تفاوت Unicode و UTF-8 را توضیح دهید؛
- متن فارسی را encode/decode کنید؛
- اختلاف نویسه‌های `ي/ی` و `ك/ک` را تشخیص دهید؛
- تفاوت NFC با normalization فارسی را توضیح دهید؛
- نقش ZWNJ (`U+200C`) را در فارسی بررسی کنید؛
- یک normalization policy کوچک و قابل‌آزمون پیاده‌سازی کنید؛
- کیفیت یک corpus کوچک را ممیزی کنید؛
- تغییرات تعداد token/type را قبل و بعد از normalization تحلیل کنید.
