# جلسه ۰۳ — توکن‌سازی متن فارسی: فاصله، مرز واژه و BPE

**زمان:** ۱۲۰ دقیقه  
**سطح:** کارشناسی  
&#x2067;**پیش‌نیاز:** جلسهٔ ۰۱ (Unicode و ZWNJ)، جلسهٔ ۰۲ (`re` و پیش‌پردازش)&#x2069;  
&#x2067;**وابستگی نرم‌افزاری برای تمرین‌ها:** Python Standard Library؛ صرفاً JupyterLab برای اجرای notebook&#x2069;

## هدف جلسه

&#x2067;دانشجو سه خانوادهٔ توکن‌سازی را روی نمونه‌های فارسی مقایسه می‌کند: **فاصله‌به‌فاصله** (`split(' ')`)، **مرز واژه** (`\b` و قواعد صریحِ فارسی با حفظ نیم‌فاصله)، و **BPE مبتنی بر بایت UTF-8**. مقایسهٔ معیارهای توکن‌سازی واژه‌ای و زیرواژه‌ای باید با واحدهای متفاوت و بدون نتیجه‌گیری گمراه‌کننده انجام شود.&#x2069;

## خروجی‌های یادگیری

- مقایسهٔ `split(' ')` با `split()` هنگام وجود فاصلهٔ تکراری، tab، نشانه‌گذاری و ZWNJ؛
- &#x2067;تشخیص محدودیت `\w` و `\b` در مرزبندی ترکیب‌های فارسی مانند `می‌روم`؛&#x2069;
- طراحی tokenizer مبتنی بر `re` برای حروف فارسی، نیم‌فاصله، عدد، حروف لاتین و علائم؛
- پیاده‌سازی ادغام جفت‌های مجاور و بررسی مفهوم BPE مبتنی بر بایت؛
- &#x2067;محاسبهٔ precision/recall/F1 بر اساس **span واژه‌ای** برای سه روش واژه‌ای؛&#x2069;
- سنجش BPE با **بازسازی دقیق متن، تعداد زیرواژه‌ها، تنوع بایتی و میانگین بایت بر توکن** (نه F1 واژه‌ای)؛
- گزارش محدودیت آزمایش با دادهٔ مصنوعی و تحلیل خطا.

## فایل‌ها

## اجرا

از ریشهٔ مخزن:

```bash
python -m pip install -r requirements.txt
python scripts/check_environment.py
jupyter lab
```

&#x2067;Notebook را از مسیر `sessions/03_tokenization/` باز و اجرا کنید. پوشهٔ `data/` باید در کنار همان notebook بماند. برای بررسی ساختار فایل و اجرای نسخهٔ اولیه (پس از نصب `requirements-dev.txt`):&#x2069;

```bash
python scripts/validate_notebook.py sessions/03_tokenization/session03_persian_tokenization.ipynb
python scripts/execute_released_notebooks.py
```

**مهم:** &#x2067;starter باید از ابتدا تا انتها بدون exception اجرا شود؛ آزمون‌های `TODO` تا پیش از تکمیل تمرین‌ها ممکن است `FAIL` گزارش کنند و این طبیعی است.&#x2069;
