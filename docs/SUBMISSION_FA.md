# راهنمای تحویل تمرین

## نام فایل

فایل تکمیل‌شده باید دقیقاً با الگوی زیر نام‌گذاری شود:

```text
STUDENT_ID_session01.ipynb
```

`STUDENT_ID` را با شماره‌ی دانشجویی خود جایگزین کنید.

## پیش از تحویل

1. همه‌ی `TODO`ها را کامل کنید.
2. پاسخ همه‌ی `✍️ Exercise`ها و سوالات تشریحی را بنویسید.
3. از منوی Jupyter، Kernel را restart کنید.
4. تمام سلول‌ها را از ابتدا تا انتها اجرا کنید.
5. مطمئن شوید traceback یا syntax error وجود ندارد.
6. outputهای لازم را نگه دارید تا روند آزمایش قابل بازبینی باشد.
7. توضیح منابع/کمک خارجی را در بخش پایانی notebook درج کنید.

## نکته‌ی مهم درباره‌ی GitHub

**notebook حل‌شده را در repository یا fork عمومی قرار ندهید.**

انتشار solution می‌تواند هم کار خود شما و هم ارزیابی دانشجویان دیگر را تحت تأثیر قرار دهد. فایل را فقط از کانال تحویل تعیین‌شده توسط مدرس ارسال کنید.

## معیار کلی کیفیت

یک submission خوب فقط «خروجی درست» ندارد؛ باید:

- قابل‌بازتولید باشد؛
- کد خوانا و قابل توضیح داشته باشد؛
- محاسبات را انجام دهد و اعداد را hard-code نکند؛
- reasoning مناسب برای تصمیمات preprocessing ارائه دهد.
