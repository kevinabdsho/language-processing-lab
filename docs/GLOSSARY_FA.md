# واژه‌نامه‌ی جلسه ۰۱

| اصطلاح | توضیح کوتاه |
|---|---|
| **Unicode** | &#x2067;استانداردی برای تعریف و شماره‌گذاری نویسه‌ها (code pointها)&#x2069; |
| **Code point** | &#x2067;شناسه‌ی عددی یک نویسه، مانند &#x2066;`U+06CC`&#x2069; برای `ی`&#x2069; |
| **UTF-8** | &#x2067;یکی از روش‌های تبدیل code pointهای Unicode به byte&#x2069; |
| **Encoding** | نگاشت متن/نویسه‌ها به نمایش بایتی |
| **NFC** | &#x2067;فرم canonical composition در Unicode normalization&#x2069; |
| **Normalization** | تبدیل متن به یک نمایش سازگارتر بر اساس سیاست مشخص |
| **Persian normalization** | قواعد زبان‌محور مانند تبدیل `ي` به `ی` |
| **ZWNJ** | &#x2067;Zero Width Non-Joiner، کد &#x2066;`U+200C`&#x2069;؛ در فارسی معمولاً با عنوان نیم‌فاصله شناخته می‌شود&#x2069; |
| &#x2067;**Corpus / پیکره**&#x2069; | &#x2067;مجموعه‌ی متون مورد استفاده برای تحلیل یا آموزش/ارزیابی NLP&#x2069; |
| **Token** | &#x2067;یک رخداد واحد در tokenization انتخاب‌شده&#x2069; |
| **Type** | &#x2067;یک token یکتای متمایز در vocabulary&#x2069; |
| **TTR** | &#x2067;نسبت تعداد typeها به تعداد tokenها&#x2069; |
| **Data audit** | اندازه‌گیری و گزارش مشکلات/ویژگی‌های داده پیش از تغییر آن |
| **Idempotence** | &#x2067;خاصیتی که در آن اجرای دوباره‌ی transformation روی خروجی، آن را دوباره تغییر نمی‌دهد&#x2069; |


## واژه‌نامهٔ افزوده‌شده در جلسهٔ ۰۲

| اصطلاح | توضیح کوتاه |
|---|---|
| **Regular expression / regex** | الگوی متنی قابل جست‌وجو یا جایگزینی |
| **`re.search`** | &#x2067;یافتن نخستین match در متن&#x2069; |
| **`re.findall`** | &#x2067;گردآوری matchهای مستقل در فهرست&#x2069; |
| **`re.finditer`** | &#x2067;پیمایش matchها همراه با span موقعیت&#x2069; |
| **`re.sub`** | جایگزینی بخش‌هایی از متن مطابق الگو |
| **Character class** | گروهی از نویسه‌های مجاز مانند `[۰-۹]` |
| **Quantifier** | تعیین تعداد تکرار، مانند `+` و `*` |
| **False positive / False negative** | &#x2067;match نادرست / از دست رفتن match واقعی&#x2069; |
| **Preprocessing policy** | مجموعه قواعد صریح و وابسته به مسئله برای تغییر متن |
| **Invariant** | ویژگی یا شمارشی که انتظار می‌رود در تبدیل تغییر نکند |
| **Line boundary** | مرز بین خطوط/رکوردها که ممکن است مرز سند نیز باشد |
| **Redaction** | حذف یا پوشاندن دادهٔ حساس به‌جای صرفاً نرمال‌کردن آن |

## واژه‌نامهٔ افزوده‌شده در جلسهٔ ۰۳

| اصطلاح | توضیح کوتاه |
|---|---|
| **Tokenization** | تقسیم متن به واحدهایی با سیاست مشخص؛ لزوماً برابر با واژهٔ زبان‌شناختی نیست |
| **Space-to-space** | جداسازی بر اساس فقط نویسهٔ فاصلهٔ ASCII (`split(' ')`) |
| **Word boundary (`\b`)** | مرز صفرعرض بین `\w` و `\W` در regex؛ الزاماً مرز واژهٔ فارسی نیست |
| **Word span** | مختصات `(start, end)` یک توکن در متن اصلی |
| **Word-span F1** | امتیاز هم‌پوشانی دقیق spanهای پیش‌بینی‌شده و مرجع در واحد واژه |
| **Subword token** | واحد کوچک‌تر/متفاوت از واژه که در مدل‌های زیرواژه‌ای به‌کار می‌رود |
| **Byte-level BPE** | توکن‌سازی بر پایهٔ بایت‌های UTF-8 و ادغام‌های پرتکرارِ مجاور |
| **Merge budget** | حداکثر تعداد ادغام‌های آموخته‌شده در BPE |
| **Round trip** | بازسازی **دقیق** رشتهٔ اولیه از توکن‌ها پس از decode |
| **Data leakage** | استفادهٔ نادرست از دادهٔ ارزیابی هنگام آموزش یا تنظیم روش |
