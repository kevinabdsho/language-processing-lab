# واژه‌نامه‌ی جلسه ۰۱

| اصطلاح | توضیح کوتاه |
|---|---|
| **Unicode** | استانداردی برای تعریف و شماره‌گذاری نویسه‌ها (code pointها) |
| **Code point** | شناسه‌ی عددی یک نویسه، مانند `U+06CC` برای `ی` |
| **UTF-8** | یکی از روش‌های تبدیل code pointهای Unicode به byte |
| **Encoding** | نگاشت متن/نویسه‌ها به نمایش بایتی |
| **NFC** | فرم canonical composition در Unicode normalization |
| **Normalization** | تبدیل متن به یک نمایش سازگارتر بر اساس سیاست مشخص |
| **Persian normalization** | قواعد زبان‌محور مانند تبدیل `ي` به `ی` |
| **ZWNJ** | Zero Width Non-Joiner، کد `U+200C`؛ در فارسی معمولاً با عنوان نیم‌فاصله شناخته می‌شود |
| **Corpus / پیکره** | مجموعه‌ی متون مورد استفاده برای تحلیل یا آموزش/ارزیابی NLP |
| **Token** | یک رخداد واحد در tokenization انتخاب‌شده |
| **Type** | یک token یکتای متمایز در vocabulary |
| **TTR** | نسبت تعداد typeها به تعداد tokenها |
| **Data audit** | اندازه‌گیری و گزارش مشکلات/ویژگی‌های داده پیش از تغییر آن |
| **Idempotence** | خاصیتی که در آن اجرای دوباره‌ی transformation روی خروجی، آن را دوباره تغییر نمی‌دهد |
