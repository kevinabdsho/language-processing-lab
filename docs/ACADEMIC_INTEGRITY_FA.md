# صداقت علمی در آزمایشگاه

هدف آزمایشگاه فقط تولید output نیست؛ هدف این است که بتوانید مسئله را تحلیل، پیاده‌سازی و توضیح دهید.

## مجاز

- گفت‌وگو درباره‌ی مفهوم کلی با همکلاسی؛
- مطالعه‌ی documentation؛
- کمک گرفتن برای debug در سطح مفهومی؛
- ارجاع به منبع با ذکر آن.

## غیرمجاز

- کپی کردن code یا پاسخ تشریحی دانشجوی دیگر؛
- به اشتراک گذاشتن فایل حل‌شده؛
- استفاده از answer key بدون اجازه؛
- انتشار solution عمومی برای تمرینی که هنوز در حال ارزیابی است؛
- hard-code کردن خروجی‌هایی که باید محاسبه شوند.

## اصل ارزیابی

ممکن است از دانشجو خواسته شود بخشی از کد یا تصمیم preprocessing خود را شفاهی توضیح دهد. ناتوانی در توضیح submission می‌تواند نشانه‌ی نیاز به بازبینی باشد.
