# صداقت علمی در آزمایشگاه

&#x2067;هدف آزمایشگاه فقط تولید output نیست؛ هدف این است که بتوانید مسئله را تحلیل، پیاده‌سازی و توضیح دهید.&#x2069;

## مجاز

- گفت‌وگو درباره‌ی مفهوم کلی با همکلاسی؛
- &#x2067;مطالعه‌ی documentation؛&#x2069;
- &#x2067;کمک گرفتن برای debug در سطح مفهومی؛&#x2069;
- ارجاع به منبع با ذکر آن.

## غیرمجاز

- &#x2067;کپی کردن code یا پاسخ تشریحی دانشجوی دیگر؛&#x2069;
- به اشتراک گذاشتن فایل حل‌شده؛
- &#x2067;استفاده از answer key بدون اجازه؛&#x2069;
- &#x2067;انتشار solution عمومی برای تمرینی که هنوز در حال ارزیابی است؛&#x2069;
- &#x2067;hard-code کردن خروجی‌هایی که باید محاسبه شوند.&#x2069;

## اصل ارزیابی

&#x2067;ممکن است از دانشجو خواسته شود بخشی از کد یا تصمیم preprocessing خود را شفاهی توضیح دهد. ناتوانی در توضیح submission می‌تواند نشانه‌ی نیاز به بازبینی باشد.&#x2069;
