# سیاست استفاده از ابزارهای هوش مصنوعی — نسخه‌ی دانشجویی

> &#x2067;این فایل یک سیاست شفاف برای استفاده‌ی مسئولانه از AI در آزمایشگاه است. در صورت اعلام دستور متفاوت از طرف مدرس، دستور مدرس اولویت دارد.&#x2069;

## استفاده‌های قابل قبول

- درخواست توضیح درباره‌ی یک مفهوم پس از تلاش اولیه؛
- کمک برای فهم پیام خطا؛
- &#x2067;پیشنهاد روش debug؛&#x2069;
- مقایسه‌ی چند رویکرد، به شرط آن‌که تصمیم نهایی و توضیح آن متعلق به خود دانشجو باشد؛
- &#x2067;بازبینی نگارشی پاسخ، بدون جایگزین کردن reasoning دانشجو.&#x2069;

## استفاده‌های غیرقابل قبول

- تحویل مستقیم کد یا پاسخ تولیدشده بدون درک آن؛
- &#x2067;درخواست «حل کامل notebook» و تحویل همان پاسخ؛&#x2069;
- &#x2067;استفاده از solution دانشجوی دیگر یا repository حل‌شده؛&#x2069;
- &#x2067;انتشار answer key یا notebook حل‌شده در GitHub عمومی؛&#x2069;
- &#x2067;پنهان کردن استفاده‌ی قابل‌توجه از AI وقتی از شما خواسته شده منبع کمک را اعلام کنید.&#x2069;

## اصل ساده

اگر مدرس از شما درباره‌ی هر خط کد یا پاسخ تشریحی سؤال کند، باید بتوانید **بدون تکیه به ابزار خارجی** توضیح دهید که چه کاری انجام می‌دهد، چرا درست است و چه محدودیتی دارد.

## اعلام استفاده

&#x2067;در انتهای notebook بخش &#x2066;`External help / sources used`&#x2069; وجود دارد. اگر برای یک ایده‌ی غیرساده از AI یا منبع خارجی استفاده کردید، کوتاه و دقیق اعلام کنید.&#x2069;
